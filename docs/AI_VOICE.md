# AI Voice — 仕様書

WordCore の「高品質AI音声（High-Quality AI Voice）」に関する仕様を、非エンジニア向けにまとめたものです。プラン別の利用条件、上限、コストの仕組み、失敗したときの挙動を扱います。

数値はすべて実装から確認したものです。出典ファイルを各所に併記しているので、変更する際はそちらを直してからこの文書を更新してください。

> **この文書の位置づけ**
> 運用・課金・予算の考え方は [COST_CONTROLS.md](./COST_CONTROLS.md)、セキュリティ上の前提は [SECURITY.md](./SECURITY.md) にあります。重複する数値は COST_CONTROLS.md が正です。

## 1. そもそも何が「AI音声」なのか

単語カードの読み上げには **2つのエンジン** があります。ユーザーから見ると同じ再生ボタンですが、中身も費用もまったく違います。

| | 端末音声（デバイスTTS） | 高品質AI音声 |
|---|---|---|
| 実体 | iOS 内蔵の読み上げ機能 | OpenAI の音声生成 API |
| 費用 | **無料**（通信も発生しない） | **文字数課金**（後述） |
| 通信 | なし | あり |
| 必要なプラン | 全プラン | Basic / Premium |
| 品質 | 機械的 | 自然な発話 |
| 上限 | **なし**（無制限） | プランごとに上限あり |

**無料プランは端末音声のみ**で、回数制限はありません。AI音声はいっさい生成されません。

> 以前 `FREE_VOICE_LIMIT = 10` という定数がありましたが、どこからも参照されていない死んだ定数だったため削除しました。無料プランの読み上げ回数に制限はありません。

## 2. プラン別の利用条件

### 早見表

| | Free | Basic | Premium |
|---|---|---|---|
| 端末音声 | ✅ 無制限 | ✅ 無制限 | ✅ 無制限 |
| AI音声（カード表） | ❌ | ✅ **10枚まで（一度きり）** | ✅ 月400回 |
| AI音声（カード裏） | ❌ | ❌ 端末音声になる | ✅ 設定でオン |
| 音声の聴き比べ（プレビュー） | ❌ | ✅ 無料 | ✅ 無料 |
| アップグレード画面のサンプル | ✅ 無料 | ✅ 無料 | ✅ 無料 |
| 単体の読み上げ機能（Custom Voice） | ❌ | ❌ | ✅ ※現在は非表示 |

出典: `cloudflare/wordping-api/src/config.ts:81-103`、`cloudflare/wordping-api/src/planLimits.ts`

### Basic — 「10枚の一度きりの枠」

Basic の AI音声は **回数ではなく「カード枚数」** で数えます。

- **異なるカード10枚分の「表」** に対して AI音声を生成できます
- **一度きりの付与**です。更新しても、解約して入り直しても、再インストールしても、機種変更しても **再付与されません**
- 一度生成したカードは、**編集しても音声を変えても追加で枠を消費しません**（カードごとに枠が確保される方式のため）
- 生成に**失敗した場合は枠を消費しません**
- 枠を使い切った後も、**すでに生成済みの音声は再生し続けられます**（端末に保存されているため）
- カードの**裏面**は Basic では常に端末音声です
- これとは別に、**新規生成の音声の合計再生時間が月1分30秒まで**という上限があります

> なぜ「一度きり」なのか: この残高は Cloudflare の Durable Object（サブスクリプション単位の台帳）に保存され、月次リセットの仕組みを一切通しません。月ごとにリセットされる実装にすると「実質無制限」になってしまうためです。
>
> 出典: `cloudflare/wordping-api/src/lifetimeCredits.ts:7-17`、`planLimits.ts:55-59`

> 開発初期には 200 枠だった時期があり、その頃に作られた台帳は `grantSize` を持っています。後から枠数を変えても既存ユーザーの残高が勝手に読み替えられないようにするためです（`lifetimeCredits.ts:41-42`）。

### Premium — 月ごとの予算

Premium は枚数ではなく **UTC月単位の予算**で管理します。

| 予算 | 上限 |
|---|---|
| 生成回数 | **月400回** |
| 生成回数（1日あたり） | **200回** |
| 新規生成した音声の合計再生時間 | **月30分** |

- 3つすべてに余裕がある場合だけ生成されます
- **キャッシュ再生（同じ内容の再生）は一切カウントされません**
- カードの裏面も AI音声にできます（設定 → 「裏面もAI音声で読み上げる」、Premium のみ表示）
- 上限に達した場合、翌UTC月まで新規生成は止まりますが、生成済みの音声は再生できます

出典: `cloudflare/wordping-api/src/planLimits.ts:37-45`、`monthlyQuota.ts`

### プラン変更したとき

- Basic と Premium の「再生時間カウンター」は**別々に管理**されます。月の途中でプラン変更しても、新しいプランの残り時間がそのまま使えます
- **Basic の10枚の枠はプラン変更の影響を受けません**（一度きりの付与なので、Premium から Basic に戻っても再付与されません）

## 3. 選べる声

現在アプリで選べるのは **2種類**です。

| 声 | 備考 |
|---|---|
| **marin** | 既定 |
| **cedar** | |

出典: `src/lib/aiVoices.ts:4-11`

かつて提供していた `fable` / `alloy` / `ash` / `coral` / `nova` / `shimmer` は**提供終了**しています。過去に選んでいたユーザーの設定は自動的に既定の marin に戻ります（`RETIRED_AI_VOICES`）。

> サーバー側の許可リストは13種類ありますが（`config.ts:26-29`）、これはアプリ側の一覧を必ず含む必要があるための「上位集合」です。アプリから選べるのは2種類だけです。

**声の聴き比べ（プレビュー）は何回やっても無料**です。読み上げる文はアプリ側が用意した固定文で、生成結果はサーバーに共有キャッシュされ、全ユーザーで1回だけ生成されます。Basic の枠も Premium の月予算も消費しません。

## 4. 仕組み — 再生ボタンを押してから音が鳴るまで

```
[再生ボタン]
     │
     ├─ カードに自前の音声ファイルが登録されている？ → はい ─→ そのファイルを再生（通信なし・無料）
     │                                                   ↓ いいえ
     ├─ AI音声を使えるプラン？ → いいえ ─→ 端末音声で読み上げ（通信なし・無料）
     │        ↓ はい
     ├─ 端末にキャッシュがある？ → はい ─→ キャッシュを再生（通信なし・無料・上限を消費しない）
     │        ↓ ない
     ├─ AIデータ共有の許可を得ている？ → いいえ ─→ 許可ダイアログを表示（拒否なら何も送信しない）
     │        ↓ はい
     ├─ WordCore API（Cloudflare Worker）へ送信
     │        │
     │        ├─ 機能停止スイッチ → 入力文字数チェック → 利用資格確認（RevenueCat）
     │        ├─ 短期レート制限（分・日）
     │        ├─ プラン別の枠／予算チェック（Basic の10枚枠 or Premium の月予算）
     │        ↓
     │     OpenAI（gpt-4o-mini-tts）で生成
     │        ↓
     │     音声を端末へ返す（サーバーには保存しない）
     │
     └─ 端末にキャッシュして再生
```

### 押さえておきたい4点

**① キャッシュは端末に保存され、2回目以降はタダ**

生成した音声は端末内（OS管理のキャッシュ領域）に `.wav` として保存されます。同じ単語・同じ声なら2回目以降は通信もAPI呼び出しも発生せず、**どの上限も消費しません**。ストレージ不足時にOSが削除することがあり、その場合は次回再生時に再生成されます。

出典: `src/lib/tts.ts:184-192`

**② カードの音声はサーバーに保存されない**

生成された音声はそのまま端末へ流されるだけで、サーバー側には保存されません。サーバーにキャッシュされるのは、**聴き比べ用サンプル**と**アップグレード画面のプロモ音声**という、WordCore が用意した固定文だけです（約30日）。

出典: `cloudflare/wordping-api/src/routes/voice.ts`

**③ 明示的な許可がないと1文字も送信されない**

AI機能を初めて使うときに許可を求めます。許可するまで、また拒否した場合は何も送信されません。この確認は画面ごとではなく**通信の出口1箇所**で強制されているため、どの画面から呼んでも必ず通ります。許可は「設定 → ヘルプ → AI Voiceについて」からいつでも取り消せます。

出典: `src/lib/aiConsent.ts:165`、`src/lib/api/client.ts:273-276`

**④ プランの判定はサーバーが行う**

アプリが「自分は Premium です」と主張しても無視されます。サーバーが毎回 RevenueCat に問い合わせて確認します（結果は成功時5分・失敗時30秒だけキャッシュ）。アプリ側のプラン表示はあくまで画面表示用です。

出典: `cloudflare/wordping-api/src/entitlements.ts`、`config.ts:181-186`

## 5. コストの仕組み

### 何にお金がかかるのか

| 項目 | 費用 |
|---|---|
| OpenAI 音声生成（`gpt-4o-mini-tts`） | **入力文字数に比例** ← ほぼ全部これ |
| Cloudflare Worker | リクエスト数に応じた少額 |
| 端末音声 | **0円** |
| キャッシュからの再生 | **0円** |
| 聴き比べプレビュー | 全ユーザーで1回だけ生成（実質0円） |
| プロモ音声 | 同上 |

**費用は「文字数 × 生成回数」でほぼ決まります。** 再生回数ではありません。同じカードを100回再生しても、生成は最初の1回だけです。

> 💡 **具体的な単価は記載していません。** OpenAI の価格は変動するため、必ず OpenAI の料金ページで確認してください。この文書で保証できるのは「何が課金対象で、何が対象外か」という構造だけです。

### コストが暴走しないための多層防御

安いチェックから順に並んでおり、悪質なリクエストは**お金がかかる前に**弾かれます。

```
リクエストの形式 → 機能停止スイッチ → 利用資格 → 文字数上限 → レート制限 → OpenAI
    (無料)          (KV読み取り)    (RevenueCat)   (無料)      (KV)      ($$$)
```

| 防御層 | 内容 |
|---|---|
| **OpenAI プロジェクト予算** | 最終防衛線。Worker にバグがあっても超えられない唯一の上限。**必ず設定すること** |
| プラン別の枠・予算 | Basic の10枚枠 / Premium の月400回・30分 |
| 1リクエストの文字数上限 | カード音声は500文字 |
| 分あたり・日あたりの回数上限 | カード音声は20回/分、Premium 200回/日 |
| 日あたりの文字数上限 | 50,000文字/日 |
| IPアドレス単位の上限 | 端末ID単位の6倍（同一回線の複数ユーザーを誤検知しないための余裕） |
| 機能停止スイッチ | アプリを更新せずにサーバー側から機能を止められる |

詳細な数値表は [COST_CONTROLS.md](./COST_CONTROLS.md) にあります。

### 費用を左右する運用上の判断

- **文字数が費用そのもの。** 長い例文を読み上げる機能を足すと、単語1語の読み上げより桁違いに高くつきます
- **リトライしない設計。** タイムアウトは「遅い成功」と区別できないため、再試行すると二重課金のおそれがあります。Worker は OpenAI へのリクエストを**絶対に再試行しません**
- **キャッシュが効く設計ほど安い。** 同じ単語を何度も復習する使い方は、2回目以降まったく費用が発生しません

## 6. 上限に達したときの挙動

| 状況 | ユーザーに何が起きるか |
|---|---|
| Basic が10枚を使い切った | 専用ダイアログを表示。「無料の音声を使う」を選ぶと以降は端末音声になる |
| Premium が月の上限に達した | 新規生成は翌UTC月まで停止。生成済みは再生可能 |
| Premium が1日の上限に達した | 翌UTC日まで停止 |
| 通信できない | 端末音声にフォールバック。**読み上げが無反応になることはない** |
| AI生成が失敗した | 端末音声にフォールバック。枠は消費しない |
| 許可していない／取り消した | 端末音声のまま。何も送信されない |

**重要な設計方針が2つあります。**

**① 再生ボタンが無反応になることは絶対にない。** AI音声が使えない理由が何であれ、端末音声に落ちます。無料プランとまったく同じ挙動になるだけで、機能が死ぬことはありません。

**② 枠を使い切っても、すでに生成した音声は聴き続けられる。** 枠が止めるのは「新規生成」だけです。端末のキャッシュから再生する経路は通信を一切行わないため、原理的に費用が発生せず、したがって止める理由もありません。

出典: `src/lib/tts.ts:1040-1054`、`src/components/VoiceCreditsExhaustedDialog.tsx`

### 「無料の音声を使う」について

これは**設定であって、権利の剥奪ではありません**。オンにすると以降 AI音声の生成を試みなくなるため、ダイアログが毎回出るのを止められます。設定画面で声を選び直せば解除されます。

## 7. データの取り扱い

AI音声を1回生成するとき、何がどこへ送られるかです。

| 送信先 | 送られるもの | 保存 |
|---|---|---|
| WordCore API (Cloudflare) | カードの表または裏のテキスト、言語、声、形式、カードID、インストールID、RevenueCat のユーザーID | テキストは**ログにもKVにも保存しない**。識別子はソルト付きハッシュのみ |
| OpenAI | **テキスト・声・モデルのみ** | OpenAI 側の規約に従う |

- **OpenAI には識別子が一切渡りません。** 誰のリクエストかは OpenAI からは分かりません
- サーバーのログに残るのは、エンドポイント名・ステータス・処理時間・文字数・リクエストIDと、ソルト付きハッシュだけです。**本文は記録されません**
- カードに登録した自前の音声ファイルは**どこにも送信されません**
- アップグレード画面のプロモ音声だけは例外で、**識別子を一切伴いません**（未加入でも聴けるため）

出典: `cloudflare/wordping-api/src/log.ts`、`identity.ts:50-62`、`openai.ts:112-115`
